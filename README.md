# Emergency-Hospital-Search-Assistant

A smart, fast, and user-friendly web app that helps users **locate nearby hospitals** in real-time based on diseases, symptoms, and availability — especially helpful during emergencies.

---

##  What It Does

This website allows users to:

✅ Search for hospitals based on symptoms or disease  
✅ View hospital details including timings and doctor availability  
✅ Filter hospitals by specialization  
✅ Use a clean, responsive UI for ease-of-use in urgent situations

## 🛠️ Features Breakdown

### 🔐 Login & Signup
- Users can sign up with a username/password
- Only registered users can access the search features

###  Hospital Search
- Search hospitals based on disease or keyword
- Clickable disease cards lead to filtered hospitals

### 👩‍⚕️ Doctor & Hospital Details
- Hospital list includes:
  - Name
  - Timings
  - Doctor info
  - Specialization
  - assurance

##  How to Run Locally

1. Clone the repo:
   ```bash
   git clone https://github.com/MeghaaVerse/Emergency-Hospital-Search-Assistant.git
   ```
2. Navigate to the project folder and open `mini.html` in your browser.

> ⚠️ No server required — fully client-side.
